操作説明 (User Guide)

ショートカットキー

  • ? / Shift + / : 操作説明画面の開閉
  • Esc : モーダル画面を閉じる / ノード選択の解除
  • Delete / Backspace : キャンバス上で選択中のノードを削除

キャンバス操作

  • キャンバスドラッグ: 表示領域のパン（移動）
  • マウスホイール / 拡大・縮小ボタン: ズーム表示
  • ノードクリック: ノードの選択と直接編集（ラベル編集・ノード追加・削除）

基本記法

機能 入力例 出力・説明
基本構造 [S [NP ...] [VP ...]] 角括弧による階層的ネスト構造
単語直書き [N cat] 範疇ノード直下に語彙項目を配置
三角形省略（句） [^NP a wug] 範疇名の下に底辺を持つ二等辺三角形を描画
三角形省略（語彙） [NP [^ a wug]] 語彙の直前に ^ を付与して三角形を描画
Xバー（プライム） [N' [N cat]] アポストロフィによる中間投射表記
Xバー（マクロン） [N̄ [N cat]] マクロン文字による中間投射表記
下付き添字 [t_i], [DP_1] アンダースコア以降を下付き文字として表示
移動矢印 [NP:wh ...] [t_i] 同一タグ（@1等）またはラベルを持つノード間を曲線矢印で接続

エクスポート

  • 画像コピー: PNG画像をクリップボードに直接コピー
  • PNG / SVG: 画像ファイルとしてローカルへ保存
  • エクスポート: LaTeX（forest / tikz-qtree）、Mermaid、JSON、Unicodeテキストを出力
  • 共有: 編集中のデータを埋め込んだURLをクリップボードにコピー

操作説明 (OPERATING INSTRUCTIONS)

ショートカット (SHORTCUTS)

  • ? または Shift + / : 操作説明画面を開閉します。
  • Esc : 操作説明画面を閉じます。

構文木の書き方 (SYNTAX TREE NOTATION)

  • 基本構文：[範疇 語彙] または [句 [範疇 語彙] ...] の形式（Penn Treebank形式）で記述します。
    例：[S [NP [D The] [N student]] [VP [V read] [NP [D a] [N book]]]]
  • 三角形省略（Roof）：[^語彙] または [^範疇 語彙] で内部構造を省略した三角形を表示します。
    例：[^NP a wug] または [NP [^ a wug]]
  • 移動矢印（Movement Arrow）：移動元と移動先に同じタグを付与すると下部を通る矢印が自動描画されます。
    例：[NP:wh Which book] と [NP:wh t_i]、または [NP@1 ...] と [t@1]
  • Xバー記号：'（プライム）または ̄（マクロン）を使用します。クイック記号バーからも入力できます。

操作方法 (CONTROLS)

  • キャンバス移動・拡大縮小：ドラッグで移動、マウスホイールまたは右上の ＋ / − ボタンで拡縮します。
  • ノード編集：キャンバス上のノードをクリックすると、ラベルや語彙を直接編集できます。
  • 画像コピー / 保存：ヘッダー右側のボタンからクリップボードコピー、SVG・PNGダウンロード、LaTeX（forest / tikz-qtree）出力が可能です。
